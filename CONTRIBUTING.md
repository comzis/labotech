# Contributing to Labotech

Thank you for your interest in contributing to Labotech.

## How to Contribute

- Fork the repository
- Create a feature branch: `git checkout -b feat/your-feature-name`
- Make your changes
- Run the test suite: `npm test`
- All 243 tests must pass before submitting
- Open a Pull Request against `main`

## Code Conventions

- Plain ES6 Node.js — no TypeScript
- No new npm dependencies without discussion
- In-memory Maps for state management
- EventEmitter patterns for async communication
- FFmpeg via `child_process.spawn`
- Follow existing naming conventions

## Reporting Issues

Please use GitHub Issues to report bugs or request features. Include:

- Labotech version
- Operating system and Node.js version
- Steps to reproduce
- Expected vs actual behaviour

## Areas Welcoming Contributions

- ETR 290 P3 SI table checks via TSDuck
- Server-side authentication
- Additional stream format support
- Documentation improvements
- Test coverage improvements

## Code of Conduct

Be respectful. This is a professional broadcast engineering tool maintained in good faith for the community.
